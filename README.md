# 🧃 RAW – Juice Product Landing Page

A fully responsive **Product Landing Page** built using **HTML5** and **CSS3**. The project showcases a premium juice brand through a visually engaging interface, creative layouts, and modern styling techniques.

## 🛠️ Tech Stack

| Technology | Purpose                                                 |
| ---------- | ------------------------------------------------------- |
| HTML5      | Semantic structure and content organization             |
| CSS3       | Styling, layout design, positioning, and responsiveness |

## ✨ Features

* Fully responsive landing page design
* Eye-catching multi-section layout
* Product showcase featuring four juice variants
* Newsletter subscription section
* Social media integration
* Custom clip-path elements and creative positioning

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/payalkacha06/raw-juice-product-page.git
```

2. Navigate to the project directory.

3. Open the `index.html` file in your preferred web browser.

## 🎯 Project Objective

This project was developed to strengthen frontend development skills by creating a visually appealing and responsive product landing page using only HTML and CSS. It demonstrates an understanding of semantic HTML, layout structuring, positioning techniques, and responsive design principles.
